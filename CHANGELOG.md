# Changelog

All notable changes, by milestone. Dates are build dates.

## M1 — Core loop, save, bignum, rng, 3D scene + pixel renderer
- `core/bignum.js`: layered big number (mantissa + exponent, exponent itself can grow into
  power-tower layers); add/sub/mul/div/pow/log/compare/floor/min/max/format; NaN-safe, saturating.
- `core/rng.js`: seeded, serialisable sfc32 generator with weighted picks, forks, state save/restore.
- `core/time.js`: injectable clock, offline-elapsed sanitiser (negative ignored, clamped to 10 years), date keys.
- `core/loop.js`: fixed-timestep loop with manual `advance()` and stall (`onGap`) hook.
- `core/save.js`: versioned localStorage saves, migrations, corrupt-save backup, checksummed text export/import, in-memory fallback.
- Three.js r170 vendored (`vendor/three`), loaded through an import map; no CDN, no build step.
- Renderer: pixelated low-res render target with nearest-neighbour upscale (setting), instanced floor,
  five themes (factory, steampunk, space, sci-fi, pixel) with seeded endless remixes, orbit/pan/zoom camera.
- `render/resources.js`: shared resource tracker + GPU audit hook (`window.__game.gpuAudit()`), unit tested.
- Tooling: ESLint flat config, node:test, Playwright (SwiftShader WebGL), Pages workflow.
- Placeholder: money ticks +1/s until production lands in M3.

## M2 — Rolling, items, backpack
- Data: `tiers.json` (12 hand tiers + endless generated tiers), `items.json` (24 templates, 8 types), `weapons.json` (7), `mutations.json` (13), `economy.json` (every tuning knob).
- `gen/tiers.js`: closed-form endless tier maths (quadratic extension), tier names/icons/colours (colour-blind safe + icon + name).
- `sim/rolling.js`: luck-scaled tier draw `P(tier >= t) = min(1, luck/odds_t)`, two-level pity, closed-form free-roll accrual, x10/x100/auto-roll unlocks, odds table.
- `sim/items.js`: item stat model (tier scaling, variants, hybrids, mutation stacking) — added as a separate module because production, combat and UI all share it.
- `sim/inventory.js`: backpack limits, sell (<= 50% of roll price), sell duplicates, fuse with documented odds + pity.
- `sim/leveling.js`: endless XP curve; `sim/economy.js`: price formulas and the single `modifiers()` hook.
- `src/game.js` (new, DOM-free controller used by UI, tests and the debug hook), `core/events.js` (transient event queue).
- UI: HUD, dock, roll panel (odds table, pity bars), backpack panel (sell, fuse with live odds, sell duplicates, bigger backpack), throttled ARIA announcements.
- Save format **v1** frozen at the end of this milestone (fixture `tests/fixtures/save-v1.json` was produced by the real v1 serializer).
- First level now takes ~11 rolls (xp base 10) so the first minute has a reward.

## M3 — Placement, production, refiners, mutations
- `sim/production.js`: closed-form production flow solver (cap → add → refine → multiply → sell; loops/dead ends blocked and flagged; dynamo aura, clover luck, lamp xp; exact per-dropper income attribution).
- `sim/placement.js`: bounds/occupancy rules, place/move/swap/rotate/pick up/sell, base expansion (to 32x32, then soft-capped mega-tile bonus), layout presets, lane-based auto-layout.
- `sim/refiners.js` + `data/refiners.json`: mutation refinery (re-roll, transfer, combine with documented odds).
- Save format **v2** with a real v1→v2 migration, tested against the v1 fixture; hostile/corrupt v2 data is sanitised.
- 3D: instanced items per shape (merged primitives), direction arrows, rarity gems, mutation halos, blocked markers, flow dots, placement ghost (ring = valid, cross = invalid) + text label, ray-cast grid picking.
- `core/input.js`: action-based input, remappable bindings, conflict detection. UI: placement controller (click/tap, drag to move/swap, R/X/Delete/Esc), Base panel (income per item, inspector, presets, expansion), Refinery panel.

## M4 — Levels and procedural generation
- `sim/rewards.js` + `data/rewards.json`: hand-written level rewards (2–20 with gaps) and a documented generation formula for every level forever (money in roll prices, free rolls, backpack slots, luck, free expansion, gear slots, free-roll cap, tier-scaled items). Ledger `rewards.levelClaimed` guarantees each level pays exactly once, including across reloads.
- Permanent bonuses (`state.bonus`) feed `economy.modifiers()`: backpack slots, luck, gear slots, free-roll cap.
- Burst safety: thousands of level-ups at once stay fast; surplus items convert to money instead of flooding the backpack.
- Generation tests: names (determinism, uniqueness), every template generates finite stats at every tier, variants/hybrids rates, endless generated mutations/tiers/themes.
- UI: level reward toasts + next-level reward preview.

## M5 — Rebirth, endless prestige layers, economy simulator
- `gen/layers.js` + `data/rebirth.json`: prestige layers 0–2 hand-made, every layer k >= 3 generated by the same rules (name, currency, effect kind, threshold, multiplier curve, tree of 12 upgrades incl. an endless sink, rule). All Big maths, so layer 50000 works.
- `sim/rebirth.js`: gain = floor((R/threshold)^0.5) x lower-layer boost, `1 + a*total^b` permanent multipliers (soft power curve), tree purchases, cascade resets, each prestige = next themed region; confirmation with a list of what is lost/kept.
- Rebirth panel (endless layers, confirm dialog with focus trap and Esc), live region theme switch.
- `scripts/simulate-economy.js` + `scripts/lib/bot.js`: scripted bot plays simulated days with the real sim and checks: no stall, no skippable layer (+ spam and never-prestige baselines), rolling payback, rebirth timing bounds, finite numbers. **It found four real exploits/runaways, all fixed** (BUGS.md 13-16).
- Economy calibration (all in data files): xp base 25, roll price 10*(1+(L-1)/10)^3 (polynomial), multiplier-type item stats grow polylogarithmically in tier value, generator luck/xp stack additively, level-reward luck is additive, reward items are tiered relative to your luck, mass level-ups are closed form.
- Verified by the simulator over 5 simulated days: 8/8 economy checks pass (see VERIFICATION.md).

## M6 — Stores, rewards, quests, offline progress
- `sim/shop.js` + `data/shop.json`: roll / gear / luck upgrade shops (price = baseK x rollCost x growth^level, endless), timed boosters, backpack tiers, daily rotating shop seeded by date (items cost 80% of the expected roll cost). Every purchase checks the balance first.
- `sim/quests.js` + `data/quests.json`: 42 quests + 14 achievements + endless generated quests, daily reward with streaks, playtime rewards, level-milestone chests, rotating 6-hour chests. Every reward is claimed through a ledger, so it can only be granted once (also across reloads).
- `sim/offline.js`: closed-form offline progress (income x time split at booster expiries, free-roll accumulation, booster countdown); negative elapsed ignored, absurd elapsed clamped to 10 years; welcome-back screen. Tested against tick-by-tick simulation (rel. error < 1e-6) and for speed (10 years in < 100 ms).
- Save format stays **v2** (new fields are additive with defaults).
- Shop and Rewards panels (badge for claimable rewards).

## M7 — Combat, weapons, bosses, combat simulator
- `gen/monsters.js`, `gen/bosses.js`, `data/enemies.json`, `data/bosses.json`: endless seeded waves and bosses (mechanics: phase shield, summoner, enrage, shockwave, regeneration, plating, swiftness; every 5th boss adds one more mechanic).
- `sim/combat.js`: pure deterministic combat (seeded; no DOM/Three/clock): turrets on the grid + equipped weapons fighting automatically, 5 damage types with resistances/weaknesses, crit / splash / chain / pierce / slow / burn, manual avatar (move, aim, dash, nova, shield, weapons +50%), boss mechanics and drops (weapon with unique mutation `boss:<n>`, money, a free upgrade level), rush ("arena") waves, closed-form wave forecast and offline wave resolution, loss penalty min(2% money, 30 s income) that never touches items or the save.
- `scripts/simulate-combat.js`: proves a reasonable tier-t build beats waves up to ≥3t and loses before 3t+18 (never impossible, never trivial), bosses sit in their intended band, hp/numbers are finite forever, manual play beats waves auto play cannot.
- Render: pooled instanced enemies with hp bars (cap by quality), capped effects (tracers/pops/nova rings, none flashing with reduced motion), fight camera; UI: Combat panel (forecast, gear slots, boss details, arena rush), fight overlay with touch-sized ability buttons.
- `M` toggles manual control; WASD/arrows move, mouse aims, Shift dash, Q nova, E shield, Esc leaves.

## M8 — Customization, accessibility, touch, audio
- `core/audio.js`: all sounds are synthesised with WebAudio (no files). Pure `soundDef(name, {tier, flavour})` (unit tested), voice cap, per-sound rate limits, master/sfx/music volumes, mute, ambient music loop whose scale follows the region theme, and a **caption for every sound** (shown as on-screen captions when enabled).
- `ui/settings.js` (Settings panel): pixel size, graphics quality (rebuilds pools, no GPU leak across switches), number format (suffix / scientific / engineering), game speed (0.5x-4x) and pause, region theme override, base floor skin, accent colour, camera speed / invert / sway, show or hide panels and status chips, text size, motion (auto / reduced / full), high contrast, colour-blind rarity border styles (rarity always also has name + icon), captions, sound, **key remapping with conflict detection**, save export / import / reset.
- `sim/state.js`: `defaultSettings` / `sanitizeSettings` (every setting is validated on load, so a hand-edited save cannot break the UI); item nicknames and skin colours persist.
- `ui/touch.js`: touch bar for placement (rotate / pick up / sell / cancel), virtual joystick for the arena; all controls >= 44 px; `prefers-reduced-motion` honoured by default.
- `ui/a11y.js`: ARIA live announcements throttled to one per 1.5 s (latest wins, urgent ones bypass).
- Fixes found while testing (BUGS.md 24-26): collapsible Settings sections re-collapsed on every refresh; Escape did not close an open panel; placement and main both handled Escape.
- New e2e: `e2e/m8-customization-a11y.spec.js` (16 tests).

## M9 — Tests, soak, bug fixes, docs, requirements review
- `e2e/soak.spec.js` (`npm run test:soak`): 5-minute random-input soak (console errors, JS heap after gc, GPU resources, DOM nodes, NaN/Infinity text, frame loop alive) and a long-numbers soak (tower-sized money/prestige currencies, every panel x every number format, save/export/reload). The default `npx playwright test` skips it.

- README (setup, controls, every rule and formula, add-by-data guides, tests, simulators, Pages deploy), VERIFICATION.md (what was checked, results, what could not be verified, requirements review), BUGS.md up to #29.
- Final run: lint clean, 217 unit tests, 56 e2e tests, both simulators (`--quick`) pass; 30-day economy simulation passes 8/8 (run before the final level-cap change).

# Follow-up project: onboarding, clarity, speed, index, redesign, reveals, hosting

## F1 — Tutorial engine, skip confirmation, data
- `sim/tutorial.js` + `data/tutorial.json`: pure tutorial state machine (no DOM, no clock). 16 data-driven steps (one sentence of at most 20 words each, enforced by a test); each step advances by itself when its condition holds (stat since the step began, money earned, a UI flag, or "Got it"). Saved with the game (resumable after reload), replayable, never reached by a surprise on old saves.
- Assists (documented in README): a top-up of roll money, a free roll, and **practice items** (worth $0, so replaying can never farm money) when the backpack lacks what a step needs; a scripted **demo wave** (no penalty, no wave progress) in `sim/combat.js`.
- Small tutorial rewards are paid exactly once per save (ledger), also on replay; skipping a step never pays its reward.
- `ui/tutorial.js`: spotlight ring + one-sentence card. The overlay never blocks input and never steals focus; ring pulse stops with reduced motion; each step is announced to screen readers; "Skip this step" appears when a step is stuck for 20 s.
- Skipping asks "Skip the tutorial?" with what you would miss and three choices (Keep learning = default focus and Esc, Skip for now, Skip and don't ask again); a Resume chip appears after "Skip for now"; Settings → Help and tutorial replays it.
- New `choiceDialog` (focus-trapped, any number of choices). e2e helper skips the tutorial by default so older tests keep their meaning.

## F2 — Tutorial steps, tips, Relaxed mode (and the speed engine)
- All 16 tutorial steps work end to end; `e2e/f2-tutorial-walk.spec.js` plays them with real clicks on what the spotlight shows (found and fixed: the spotlight pointed at a clipped Place button inside a scrolling panel, so targets are now scrolled into view; a fuse assist that could count a higher-tier belt).
- `data/tips.json` + `sim/tips.js` + `ui/tips.js`: one-time contextual tips, a Tips-seen list, a setting to turn them off. (Found by a test: a tip seen at playtime 0 was stored as `0`, which is falsy, so it could fire again.)
- `data/difficulty.json` + `sim/difficulty.js`: first-run Relaxed/Standard choice, changeable in Settings; exact differences documented in the README and checked by both simulators (`--difficulty relaxed`).
- `data/speed.json` + `sim/speed.js`: pure unlock rules (level, rebirths, layer count, tree, upgrade) with endless generated speeds; loop scaling bounded per frame; locked speeds refused in `game.setSetting`; playtime counts real seconds. (UI selector with locked options is in Settings.) An old test that expected `gameSpeed: 3` to reset to 1 was changed: any number is now stored and *clamped to the unlocked speeds at use*.
- Simulator note: an income-ratio check for Relaxed was meaningless in an exponential economy (10^5.4); replaced by a time-based check (third prestige layer 9% sooner).

## F3 — Tooltips, income breakdown, Help, feedback, undo, simple/advanced UI
- `data/glossary.json` + `sim/glossary.js` + `ui/tooltips.js`: data-driven tooltips/popovers (hover, focus, tap) for stats, item types, rarities, mutations, hybrids and HUD numbers; `statParts` gives item cards structured stats. Tests: every tooltip id and every stat of every template resolves.
- `sim/explain.js` + `ui/income.js`: "Why is my income this?" (click the Income number): each line, each item's effect, every multiplier in order with its source, blocked/idle items. `economy.modifierSteps` splits the modifiers by source. Test: the listed lines add up to the income exactly.
- `data/help.json` + `sim/help.js` + `ui/help.js`: searchable Help (articles, glossary, real odds table, rebirth worked example, formulas in plain words).
- `sim/undo.js`: undo for place / move / swap / pick up / sell / sell duplicates (20 s, 10 actions, anti-farming rules), `Z` and an Undo chip.
- `data/disclosure.json` + `sim/disclosure.js` + `sim/unlock.js`: progressive disclosure with unlock toasts and NEW badges; Settings -> Advanced UI shows everything. The speed unlock rules now share `sim/unlock.js`.
- Friendly default number format (`12,345`), larger default text on phones, "Need $X more" and one-click fixes for blocked actions.
- Changed tests (intended UI/behaviour changes): `tests/input.test.js` rebinding used `KeyZ`, which is now Undo; `tests/migration.test.js` default number format is now `friendly`; the e2e helper turns on the Advanced UI (older tests click every panel from level 1) and answers the first-run pace dialog.

## F4 — Game speed is unlocked, not given
- Rules in `data/speed.json` (2x at level 10, 4x at level 30, 8x after the first rebirth, then 16x, 32x, 64x ... forever from rebirth counts), requirement shared with disclosure in `sim/unlock.js`; slow speeds (0.5x, 0.75x) are never locked and the Settings text explains the difference.
- HUD speed button (appears with the first faster speed) and the Settings selector with locked options and their requirement; locked speeds are refused in the simulation (`game.setSetting`), and a saved locked speed is clamped on load.
- Speed scales only the simulation: bounded work per frame at any speed (step grows above 4x, combat sub-stepped at <= 0.1 s), playtime counts real seconds, offline progress and saves are unaffected (tests at every speed).
- Found and fixed: a hidden-dock-button fallback in the tutorial spotlight (BUGS #36).
